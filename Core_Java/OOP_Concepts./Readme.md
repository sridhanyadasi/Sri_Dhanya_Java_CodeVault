# Object-Oriented Programming (OOP) in Java

## Introduction

Object-Oriented Programming (OOP) is a programming approach based on Classes and Objects.

Java follows the Object-Oriented Programming approach to organize programs into reusable and manageable components.

In OOP, data and the methods that operate on that data are grouped together using classes and objects.

For example, in a Student Management System, Student can be a class containing student details such as name, roll number, and marks, along with methods to display or update those details.

## Why Do We Use OOP?

- To organize code using classes and objects.
- To reuse existing code.
- To protect data from unauthorized access.
- To make applications easier to maintain.
- To reduce code duplication.
- To develop large and complex applications in a structured way.

## Main Principles of OOP

Java OOP is commonly explained using four main principles.

### 1. Inheritance

Inheritance allows one class to acquire the properties and methods of another class.

**Why do we use it?**

- To reuse existing code.
- To reduce code duplication.
- To establish relationships between classes.

Example: A Car class can inherit common properties and methods from a Vehicle class.

### 2. Polymorphism

Polymorphism means one name or interface can represent different behaviours.

**Why do we use it?**

- To provide different implementations.
- To improve flexibility.
- To support method overloading and method overriding.

Types:
- Compile-time Polymorphism (Method Overloading)
- Runtime Polymorphism (Method Overriding)

### 3. Encapsulation

Encapsulation means combining data and the methods that operate on that data into a single unit and controlling access to the data.

**Why do we use it?**

- To protect data.
- To control access to class variables.
- To maintain data consistency.

Example: Declaring variables as private and providing public getter and setter methods.

### 4. Abstraction

Abstraction means hiding implementation details and showing only the necessary functionality.

**Why do we use it?**

- To hide internal implementation.
- To reduce complexity.
- To expose only required operations.

Abstraction can be implemented using:
- Abstract Classes
- Interfaces

## Other Important OOP Concepts

### Class

A class is a blueprint used to create objects. It defines variables and methods.

### Object

An object is an instance of a class. It represents an entity with state and behaviour.

### Constructor

A constructor is a special member used to initialize an object when it is created.

### Method Overloading

Defining multiple methods with the same name but different parameter lists in the same class.

### Method Overriding

Providing a subclass-specific implementation of a method inherited from a parent class.

## Types of Inheritance in Java

- Single Inheritance
- Multilevel Inheritance
- Hierarchical Inheritance

Java does not support multiple inheritance through classes. However, a class can implement multiple interfaces.

## Advantages of OOP

- Code reusability through inheritance.
- Data protection through encapsulation.
- Flexibility through polymorphism.
- Reduced complexity through abstraction.
- Better code organization.
- Easier application maintenance.

## Limitations of OOP

- Requires proper planning and design.
- Can introduce unnecessary complexity in small programs.
- Object creation and management may require additional memory.
- Beginners need time to understand the relationships between classes and objects.
