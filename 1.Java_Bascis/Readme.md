# Java Basics

## Introduction

This section contains basic Java programs that help beginners understand the fundamental concepts of Java programming.

It covers arrays, strings, type promotion, and basic operations performed using these concepts.

The programs are organized into separate folders based on their topics to make learning and practice easier.

## Topics Covered

### 1. Arrays

Arrays are used to store multiple values of the same data type in a single variable.

Topics include:

- One-Dimensional Arrays
- Two-Dimensional Arrays
- Array Declaration and Initialization
- Accessing and Updating Array Elements
- Array Operations and Examples

### 2. Strings

Strings are used to store and manipulate sequences of characters.

Topics include:

- String Creation and Initialization
- Predefined String Methods
- String Operations
- StringBuffer
- StringBuilder

### 3. Type Promotion

Type promotion is the process of automatically converting a smaller data type into a larger compatible data type during an expression or operation.

Topics include:

- Implicit Type Conversion
- Type Promotion in Expressions
- Numeric Data Type Conversion

## Folder Structure

- `Arrays/` – Contains one-dimensional, two-dimensional, and other array programs.
- `Strings/` – Contains String, predefined String methods, StringBuffer, and StringBuilder examples.
- `TypePromotion/` – Contains programs demonstrating type promotion in Java.

## Learning Outcomes

After completing these programs, you will be able to:

- Understand and work with arrays in Java.
- Perform operations on one-dimensional and two-dimensional arrays.
- Create and manipulate strings.
- Use predefined String methods.
- Understand the differences between String, StringBuffer, and StringBuilder.
- Understand type promotion and type conversion.
- Write basic Java programs using these concepts.

## Purpose

The purpose of this section is to build a strong foundation in Java programming before moving on to object-oriented programming and advanced Java concepts.
