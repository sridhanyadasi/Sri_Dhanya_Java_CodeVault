# One-Dimensional Arrays in Java

## Introduction

A one-dimensional array is used to store multiple values of the same data type in a single row.

Each element can be accessed using its index, starting from 0.

## Topics Covered

- Array declaration
- Array creation
- Array initialization
- Accessing array elements
- Updating array elements
- Traversing an array
- Using loops with arrays

## Learning Outcomes

- Declare and initialize one-dimensional arrays.
- Access elements using array indexes.
- Read and display array elements.
- Perform operations on array elements.
- Use loops to traverse an array.
