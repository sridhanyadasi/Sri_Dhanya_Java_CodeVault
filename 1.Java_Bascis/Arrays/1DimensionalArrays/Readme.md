# One-Dimensional Arrays in Java

## Introduction

A one-dimensional array is used to store multiple values of the same data type in a single row.

Each element can be accessed using its index, starting from 0.

## Topics Covered

- Array declaration
- Array creation
- Array initialization
- Accessing array elements
- Updating array elements
- Traversing an array
- Using loops with arrays
- Passing and returning arrays
- Shallow copy and deep copy
- Anonymous arrays
- Variable arguments (VarArgs)
- Array insertion and deletion

## Packages and Programs

This package contains programs related to array operations, array copying, anonymous arrays and VarArgs.

| ReturningAnonymousArray.java | Shows how to return an array from a method. |

| Trial.java | Contains additional array practice. |
| VarArgsAvg.java | Calculates an average using variable arguments. |
| VarArgsFindMax.java | Finds the maximum value using variable arguments. |
| VarArgsMultiply.java | Multiplies values using variable arguments. |

### 2. com.te.oneDArrays1

| Program | Description |

## Learning Outcomes

- Understand different one-dimensional array operations.
- Pass arrays to methods and return arrays from methods.
- Understand shallow copy and deep copy.
- Work with variable arguments.
- Insert and remove array elements.
