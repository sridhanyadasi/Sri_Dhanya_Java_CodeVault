# Array Programs in Java

## Introduction

An array is used to store multiple values of the same data type in a single variable.

Java arrays allow us to access, modify, search, sort and perform operations on multiple elements using indexes.

## Topics Covered

- Array declaration
- Array initialization
- Taking array elements from console
- Printing array elements using loops
- Enhanced for loop
- Character arrays
- Finding maximum and minimum elements
- Finding the frequency of elements
- Reversing an array
- Sorting an array
- Finding the sum of elements
- Performing operations on array elements

## Packages and Programs

### 1. com.te.arrays

This package contains programs related to array declaration, traversal, searching, sorting and mathematical operations.

| Program | Description |
|---|---|
| CharactersArray.java | Demonstrates working with character arrays. |
| DeclareAndInitialize.java | Demonstrates array declaration and initialization. |
| DeclareAndTakingFromConsole.java | Creates an array by taking input from the console. |
| EnhancedForLoopPrintdoubleVal.java | Prints array elements using the enhanced for loop. |
| FrequencyOfArray.java | Finds the frequency of array elements. |
| FruitNames.java | Stores and displays fruit names using an array. |
| MaximumAndMinimum.java | Finds the maximum and minimum elements in an array. |
| PrintArrayForLoop.java | Prints array elements using a for loop. |
| ReverseArray.java | Reverses the elements of an array. |
| SortCharArray.java | Sorts the elements of a character array. |
| SquareOfElements.java | Calculates the square of each array element. |
| SumOfElements.java | Calculates the sum of array elements. |
