# Array Practice Programs in Java

## Introduction

This project contains Java programs based on different array operations and problem-solving techniques.

It focuses on searching, rotating, comparing and performing mathematical operations on arrays.

## Topics Covered

- Concatenation of two arrays
- Counting duplicate elements
- Finding common elements between arrays
- Finding the largest and second-largest elements
- Left and right array rotation
- Checking palindrome arrays
- Reversing array elements
- Finding the sum of array elements
- Finding the sum of last digits
- Finding the union of two arrays

## Packages and Programs

### 1. com.te.arrays1

This package contains array-based logical programs and problem-solving examples.

| Program | Description |
|---|---|
| ConcatenateOf2Arrays.java | Combines two arrays into a single array. |
| DuplicateArrayCount.java | Counts duplicate elements in an array. |
| IntersectionOf2Arrays.java | Finds common elements between two arrays. |
| LargestElement.java | Finds the largest element in an array. |
| LeftRotateArray.java | Rotates array elements towards the left. |
| PalindromeArray.java | Checks whether an array is a palindrome. |
| ReverseArray.java | Reverses the elements of an array. |
| RightRotation.java | Rotates array elements towards the right. |
| SecondLargestElement.java | Finds the second-largest element in an array. |
| SumOfAllElements.java | Calculates the sum of all array elements. |
| SumOfLastDigits.java | Calculates the sum of the last digits of array elements. |
| UnionOfArray.java | Finds the union of two arrays. |

## Learning Outcomes

- Perform operations on single and multiple arrays.
- Find duplicate and common elements.
- Find the largest and second-largest elements.
- Rotate and reverse array elements.
- Check palindrome arrays.
- Solve array-based logical problems.
