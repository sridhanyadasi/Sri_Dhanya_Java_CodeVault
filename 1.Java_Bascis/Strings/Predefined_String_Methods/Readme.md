# Predefined String Methods in Java

## Introduction

Java provides several predefined methods in the String class to perform different operations on strings.

These methods help compare, search, extract, modify, and process string values.

## Topics Covered

- Finding string length
- Comparing strings
- Checking string equality
- Converting strings to uppercase and lowercase
- Extracting characters
- Extracting substrings
- Searching for characters or text
- Replacing characters or text
- Removing leading and trailing spaces

## Learning Outcomes

- Use predefined String methods.
- Compare two strings using appropriate methods.
- Extract characters and substrings.
- Search and replace text.
- Perform common string operations.
