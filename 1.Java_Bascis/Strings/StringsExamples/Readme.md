# String Programs in Java

## Introduction

A String in Java is a sequence of characters used to store and manipulate text.

Java provides the String class to perform operations such as concatenation, comparison, searching and modification.

## Topics Covered

- String declaration and initialization
- String concatenation
- String reversal
- Checking palindrome strings
- Checking anagrams
- Extracting substrings
- Changing letter cases
- Capitalizing the first letter of a word
- Reversing words in a sentence

## Packages and Programs

### 1. com.te.strings

This package contains programs related to String manipulation and logical operations.

| Program | Description |
|---|---|
| Anagrams.java | Checks whether two strings are anagrams. |
| CapitalizedOf1stLetter.java | Capitalizes the first letter of a string. |
| ConcatenationOfStr.java | Combines two or more strings. |
| Example.java | Demonstrates basic String operations. |
| FirsttLettersWillBeSmall.java | Converts the first letters of words into lowercase. |
| Practice.java | Contains additional String practice programs. |
| ReverseWords.java | Reverses the order of words in a sentence. |
| StrPalindromeOrNot.java | Checks whether a string is a palindrome. |
| SubString.java | Extracts a part of a string using substring operations. |

## Learning Outcomes

- Create and initialize strings.
- Perform string concatenation.
- Reverse strings and words.
- Check anagrams and palindrome strings.
- Extract substrings.
- Change the case of characters.
- Solve string-based logical problems.
