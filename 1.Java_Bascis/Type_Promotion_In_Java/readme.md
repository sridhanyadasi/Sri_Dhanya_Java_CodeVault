# Type Promotion in Java

## Introduction

Type promotion in Java is the automatic conversion of a smaller compatible data type into a larger data type during certain expressions and operations.

It helps Java perform calculations involving different numeric data types.

## Topics Covered

- Implicit type conversion
- Numeric type promotion
- Type promotion in expressions
- Arithmetic operations with different data types
- Conversion of smaller data types into larger data types

## Learning Outcomes

- Understand type promotion in Java.
- Identify how Java handles different numeric data types in expressions.
- Understand automatic type conversion.
- Perform arithmetic operations using different data types.
