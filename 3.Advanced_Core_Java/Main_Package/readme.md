

# Main Package (`mainPackage`)

## 1. Introduction

The `mainPackage` folder contains a Java class named `MainClass.java`.

This package can be used to understand how Java classes are organized inside user-defined packages and how a main class can be used to execute a Java program.

## 2. Package Structure

```text
mainPackage/
│
└── MainClass.java
```

## 3. File Explanation

### MainClass.java

**Purpose:**

This file represents the main class inside the `mainPackage` package.

It can be used to understand:

- Package declaration
- Class declaration
- Main method
- Program execution
- Object creation, if present

## 4. Important Concepts

### Package Declaration

A Java source file can declare its package at the beginning.

```java
package mainPackage;
```

### Main Method

The main method is the standard entry point for launching a Java application.

```java
public static void main(String[] args) {

    System.out.println("Welcome to Java");
}
```

## 6. Learning Outcomes

- Understand user-defined packages.
- Declare a package in Java.
- Understand the main method.
- Organize Java classes using packages.

## 7. Conclusion

The `mainPackage` package provides a basic example of organizing a Java class inside a user-defined package.
