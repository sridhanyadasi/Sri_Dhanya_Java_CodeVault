# Object-Oriented Programming (OOP) in Java

## 1. Introduction

Object-Oriented Programming (OOP) is a programming approach based on classes and objects.

It helps developers organize programs into reusable and manageable components.

Java is an object-oriented programming language that uses classes and objects to represent real-world entities and their behaviour.

For example, in a Student Management System, Student can be a class, and individual students can be objects of that class.

## 2. Why Do We Use OOP?

OOP helps developers build applications that are easier to develop, maintain, reuse and extend.

Without OOP, managing a large application using only separate variables and methods can become difficult.

OOP organizes related data and operations together using classes and objects.

## 3. Basic Concepts of OOP

### 1. Class

A class is a blueprint or template used to create objects.

It defines the properties (variables) and behaviours (methods) of objects.

### 2. Object

An object is an instance of a class.

It represents an entity that has its own data and can perform operations defined by its class.

### 3. Encapsulation

Encapsulation is the process of wrapping data and methods together into a single unit.

It protects data by controlling access through methods such as getters and setters.

### 4. Inheritance

Inheritance allows one class to acquire the properties and methods of another class.

It helps in code reusability and reduces code duplication.

### 5. Polymorphism

Polymorphism means one name or reference can represent different behaviours depending on the situation.

In Java, it is mainly achieved through method overloading and method overriding.

### 6. Abstraction

Abstraction means hiding implementation details and showing only the necessary functionality.

In Java, abstraction can be achieved using abstract classes and interfaces.

## 4. Types of OOP Relationships and Concepts

- Single Inheritance
- Multilevel Inheritance
- Hierarchical Inheritance
- Method Overloading
- Method Overriding
- Data Hiding
- Abstract Classes
- Interfaces

**Note:** Java does not support multiple inheritance through classes, but similar functionality can be achieved using interfaces.

## 5. Advantages of OOP

- Code reusability through inheritance.
- Data protection through encapsulation.
- Flexibility through polymorphism.
- Reduced complexity through abstraction.
- Easy maintenance and modification.
- Better organization of large applications.
- Supports modular application development.

## 6. Limitations of OOP

- Requires proper planning and design.
- Can introduce additional complexity for small programs.
- Object creation and management may require additional memory.
- Beginners may need time to understand classes, objects and relationships.
- Poor class design can make applications difficult to maintain.

## 7. Applications of OOP

OOP concepts are widely used in:

- Banking applications
- E-commerce applications
- Student management systems
- Employee management systems
- Enterprise applications
- Web applications
- Android applications
- Spring Boot applications
